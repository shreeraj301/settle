# Changelog

## 0.1.0 - 2026-11-03

First public version of Settle, a client-only prototype for GST input credit.

- Match purchase bills, GSTR-2B, and a bank statement for Shree Ganesh Traders of Aurangabad, September 2026.
- Show each mismatch in plain words, with the rows side by side.
- Correct a GSTIN, mark a vendor follow-up, ignore a row with a reason, and undo.
- Approve the period, then export CSV, a spreadsheet, JSON, or a print summary.
- Switch between an owner view and a short CA client list.
- Nothing is uploaded. There is no account, database, or API. The figures are made up.
